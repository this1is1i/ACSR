# ACScientificRecommendation 项目运行说明

> 适用场景：在一台全新的 Windows 电脑上从零搭建并运行本项目。

---

## 一、前置依赖安装

### 1.1 JDK 17

1. 下载 [Eclipse Temurin JDK 17](https://adoptium.net/download/) 或 [Oracle JDK 17](https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html)
2. 安装后配置环境变量 `JAVA_HOME`，指向 JDK 安装目录（如 `C:\Program Files\Eclipse Adoptium\jdk-17.0.12.7-hotspot\`）
3. 将 `%JAVA_HOME%\bin` 添加到 `PATH`
4. 验证：`java -version` 输出 17.x

### 1.2 Maven 3.8+

1. 下载 [Maven](https://maven.apache.org/download.cgi)，解压到 `C:\maven`
2. 将 `C:\maven\bin` 添加到 `PATH`
3. 验证：`mvn -version`

### 1.3 Node.js 18+

1. 下载 [Node.js LTS](https://nodejs.org/) 并安装
2. 验证：`node -v` 输出 v18+，`npm -v` 输出 9+

### 1.4 Python 3.10+

1. 下载 [Python 3.10+](https://www.python.org/downloads/) 并安装
2. 安装时勾选 **"Add Python to PATH"**
3. 验证：`python --version` 输出 3.10+

### 1.5 MySQL 8.0

1. 下载 [MySQL Community Server 8.0](https://dev.mysql.com/downloads/mysql/8.0.html) 并安装
2. 安装时设置 **root 密码为 `qwer1234`**（或安装后自行修改配置文件中的密码）
3. 确保 MySQL 服务已启动（Windows 服务或 `mysqld`）
4. 验证：`mysql -u root -p` 能登录

### 1.6 Neo4j 5.x

1. 下载 [Neo4j Community Edition 5.x](https://neo4j.com/download-center/#community)
2. 解压或安装，启动 Neo4j 服务
3. 首次访问 `http://localhost:7474`，设置密码为 `seeworld123`
4. 验证：`bolt://localhost:7687` 可连接

## 二、获取代码

```bash
git clone <仓库地址> ACScientificRecommendation
cd ACScientificRecommendation
```

或者直接解压项目压缩包到工作目录。

## 三、MySQL 数据库初始化

### 3.1 创建数据库并导入表结构

```bash
# 登录 MySQL
mysql -u root -pqwer1234

# 在 MySQL 中执行
CREATE DATABASE IF NOT EXISTS research_db DEFAULT CHARACTER SET utf8mb4;
USE research_db;
SOURCE backend/src/main/resources/research_db.sql;
EXIT;
```

> `research_db.sql` 包含全部 13 张表（user, paper, behavior_log, post, comment, post_like, private_messages, user_contacts, user_interest_history, favourite, user_feature_snapshot, rl_training_log, paper_author_claim）的 DDL 及初始数据。

### 3.2 验证数据库

```bash
mysql -u root -pqwer1234 research_db -e "SHOW TABLES;"
```

> 应显示 13 张表。

---

## 四、Neo4j 图数据库初始化

### 4.1 创建约束与索引

在 Neo4j Browser（`http://localhost:7474`）中执行：

```cypher
:source rl-service/scripts/neo4j_schema.cypher
```

或逐条执行文件中的 `CREATE CONSTRAINT` 和 `CREATE INDEX` 语句。

### 4.2 数据迁移（MySQL + AMiner → Neo4j）

```bash
cd rl-service

# 确保已设置 Neo4j 密码环境变量
set GRAPH_NEO4J_PASSWORD=seeworld123

python scripts/migrate_to_neo4j.py --neo4j-password seeworld123
```

> 该脚本将 MySQL `paper` 表数据及 AMiner 数据集导入 Neo4j，构建 Paper 节点和 HAS_KEYWORD / AUTHOR_OF / CITE / PUBLISH_IN / CO_AUTHOR 五种关系。

---

## 五、生成论文向量

```bash
cd rl-service
python scripts/generate_paper_embeddings.py
```

> 该脚本为每篇论文生成 10 维结构特征向量（被引数/关键词数/作者数/年份等），通过投影矩阵 P(10×32) 映射为 32 维向量，写入 MySQL `paper.embedding` 列并同步到 Neo4j。

## 六、Python RL 服务环境配置

### 6.1 创建虚拟环境并安装依赖

```bash
cd rl-service

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
venv\Scripts\activate

# 安装依赖
pip install fastapi uvicorn pydantic numpy pymysql torch neo4j
```

> 如使用 GPU 训练，将 `torch` 替换为对应 CUDA 版本的 PyTorch（参见 https://pytorch.org/get-started/locally/）。

### 6.2 配置环境变量（可选，默认值即可运行）

| 环境变量 | 默认值 | 说明 |
|---------|--------|------|
| `MYSQL_HOST` | localhost | MySQL 地址 |
| `MYSQL_PORT` | 3306 | MySQL 端口 |
| `MYSQL_USER` | root | MySQL 用户 |
| `MYSQL_PASSWORD` | qwer1234 | MySQL 密码 |
| `MYSQL_DB` | research_db | 数据库名 |
| `GRAPH_NEO4J_URI` | bolt://localhost:7687 | Neo4j 连接地址 |
| `GRAPH_NEO4J_USERNAME` | neo4j | Neo4j 用户 |
| `GRAPH_NEO4J_PASSWORD` | seeworld123 | Neo4j 密码 |

> 所有默认值在 `rl-service/config.py` 中定义。如果你的数据库密码与默认不同，请设置对应的环境变量。

### 6.3 启动 RL 服务

```bash
cd rl-service
venv\Scripts\activate
uvicorn api.server:app --reload --host 0.0.0.0 --port 8000
```

验证：浏览器访问 `http://localhost:8000/health`，应返回 `{"status": "ok"}`。

## 七、Java 后端环境配置与启动

### 7.1 验证配置

检查 `backend/src/main/resources/application.yml` 中的数据库连接信息是否与本地一致：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/research_db?...
    username: root
    password: qwer1234

python:
  rec-service:
    base-url: http://localhost:8000

graph:
  neo4j:
    uri: bolt://localhost:7687
    username: neo4j
    password: seeworld123
```

### 7.2 启动后端

```bash
# 方式一：Maven 直接运行
mvn -f backend spring-boot:run

# 方式二：先打包再运行
mvn -f backend clean package -DskipTests
java -jar backend/target/research-backend-0.0.1-SNAPSHOT.jar
```

验证：浏览器访问 `http://localhost:8080/api/paper/list`，应返回 JSON 数据。

## 九、启动顺序总结

| 步骤 | 服务 | 端口 | 命令 |
|------|------|------|------|
| 1 | MySQL | 3306 | 开机自启或手动启动服务 |
| 2 | Neo4j | 7474 / 7687 | 启动 Neo4j 服务 |
| 3 | Python RL 服务 | 8000 | `uvicorn api.server:app --reload --host 0.0.0.0 --port 8000` |
| 4 | Java 后端 | 8080 | `mvn -f backend spring-boot:run` |
| 5 | Vue 前端 | 5173 | `npm run dev`（在 frontend 目录下） |

**必须按 1→2→3→4→5 的顺序启动。** 后端依赖 RL 服务提供推荐能力，前端依赖后端提供 API。

## 十二、常见问题

### Q1: `mvn` 命令找不到

确保 Maven 已安装且 `PATH` 中包含 `bin` 目录。重启终端后重试。

### Q2: MySQL 连接被拒绝

检查 MySQL 服务是否已启动。Windows 下可在「服务」中查找 `MySQL80` 并启动。

### Q3: Neo4j 连接失败

检查 Neo4j 服务状态，确认 `bolt://localhost:7687` 可访问。首次使用需在 `http://localhost:7474` 修改默认密码。

### Q4: Python 依赖安装失败

- PyTorch 体积较大，建议使用国内镜像：`pip install torch -i https://pypi.tuna.tsinghua.edu.cn/simple`
- Windows 下如遇编译错误，尝试安装 Visual C++ Build Tools

### Q5: 前端 `npm install` 失败

- 尝试清除缓存：`npm cache clean --force`
- 使用国内镜像：`npm config set registry https://registry.npmmirror.com`

### Q6: 推荐返回空或报错

确保 RL 服务（:8000）先于后端启动，且 `config.py` 中的数据库密码与实际一致。后端日志中查看 `PythonRecClient` 的错误信息。

### Q7: 知识图谱页面空白

确保 Neo4j 已启动且已完成数据迁移（第四章）。检查浏览器控制台是否有 CORS 或 500 错误。
